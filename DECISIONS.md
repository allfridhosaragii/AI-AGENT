# DECISIONS.md — Keputusan MUFAKAT

Dokumen ini memisahkan dua hal: **(A)** keputusan yang sudah diambil
(arsitektur) dan **(B)** keputusan terbuka yang butuh persetujuan owner.
Hal yang belum terverifikasi ditulis apa adanya sebagai
**belum terverifikasi** — jangan dianggap sudah diputuskan.

## A. Keputusan arsitektur yang sudah diambil

| # | Keputusan | Alasan / catatan |
|---|-----------|------------------|
| A1 | **LangGraph satu-satunya orkestrator** | Satu graph untuk alur debat → rapat → kode → audit → test → ulang. Tidak ada orkestrator kedua (mis. CrewAI/LangChain agent framework lain) agar state dan retry terpusat. Bila modul graph belum ada, CLI/MCP/Web memakai fallback penulisan langsung dan tidak gagal total. |
| A2 | **Satu server MCP (gateway) + 15 modul domain** | Satu server FastMCP bernama `mufakat`, transport stdio. 15 domain ChatGPT §7 (`core`, `communication`, `meeting`, `task`, `memory`, `project`, `git`, `filesystem`, `terminal`, `testing`, `security`, `research`, `evaluation`, `approval`, `observability`) adalah modul terpisah di `src/mufakat/mcp_server/domains/`, masing-masing dengan `CONTRACTS` (nama, deskripsi, permission, scope); server mendaftarkan semuanya (55 tool terverifikasi 20 Nov 2026). |
| A3 | **SQLite default; Postgres/Redis opsional** | Penyimpanan terstruktur memakai SQLite (SQLModel) dengan tabel `runs`, `messages`, `gate_results`, `usage_ledger` (+ entitas kolaborasi). Path DB dari `MUFAKAT_DB`; bila tidak ada, pembacaan mengembalikan list kosong. Transkrip utama tetap JSONL di `runs/<run_id>/transcript.jsonl`. Per 20 Nov 2026: `DATABASE_URL` Postgres didukung bila diset (butuh driver `psycopg`; tanpa driver, error jelas — bukan fallback diam-diam ke SQLite), `docker-compose.yml` menyediakan Postgres 16 + Redis 7, dan `storage/cache.py` memakai Redis bila `REDIS_URL` diset + server terjangkau, bila tidak fallback in-memory. Postgres/Redis TIDAK wajib. |
| A4 | **Protokol pesan MufakatMessage** | Satu pesan per baris JSONL, sesuai JSON Schema §8 dokumen arsitektur (field wajib: `run_id`, `round`, `phase`, `agent_id`, `role`, `model_family`, `content`, `timestamp`). Ringkasan maks. 1.200 karakter per agen per ronde. |
| A5 | **Konsensus: Borda count + voting** | Moderator menghitung Borda count dari ranking dan vote `approve/revise/reject`. Mufakat = usulan teratas didukung ≥ 2/3 agen dengan `approve` dan tanpa kritik `blocking` yang belum dijawab. Setelah ronde 3 tanpa mufakat, juri memutus dan dissent dicatat di spesifikasi. |
| A6 | **Anonimitas saat peer-review** | Jawaban ronde 1 dibuat tanpa melihat jawaban lain; kritik memakai label anonim (A/B/C, urutan diacak). |
| A7 | **Keamanan: tanpa otomasi web chat** | Hanya CLI/API resmi provider. Dilarang membaca kredensial CLI provider lain. `terminal_run` (MCP) hanya mengizinkan `echo`/`ls`/`pytest` tanpa shell. |
| A8 | **Gate sebelum merge** | Kode hanya masuk repo setelah gate keamanan & pengujian lolos; hasilnya disimpan di `runs/<run_id>/gates/` (JSON/SARIF). Tanpa hasil gate, `gate_report` mengembalikan status `belum terverifikasi`. Per 20 Nov 2026: setiap `mufakat run` menjalankan gate nyata atas worktree (semgrep/bandit/gitleaks/trivy/pytest/ruff) dan menulis `gates/<tool>.json` + `gates/verdict.json` + `diff/iter-01.patch`. Bila binary gate tidak ada, gate memakai fallback regex deterministik (semgrep/bandit/gitleaks) atau INFO "belum terverifikasi" (trivy) — tidak pernah pura-pura lolos. |
| A9 | **CLI sebagai antarmuka opsional/legacy — BUKAN antarmuka utama** | Produk utama sejak 20 Nov 2026 adalah **Browser-Only AI Room** (BLUEPRINT §18). Entry point `mufakat` (Typer): `run`, `debate`, `resume`, `status`, `doctor` tetap ada sebagai jalur opsional/legacy; Web dan MCP memakai logika run yang sama (`mufakat.runner`). `python -m mufakat` mendelegasikan ke CLI yang sama (diperbaiki 20 Nov 2026; sebelumnya stub). Keputusan lama "CLI sebagai antarmuka utama" sudah tidak berlaku. |
| A10 | **Adapter CLI hanya bila login terverifikasi** | `load_from_config` mengembalikan adapter CLI hanya karena entrinya ada di `providers.yaml` — tetapi adapter CLI TIDAK dipakai bila login belum terverifikasi. `_build_adapters` memakai adapter CLI hanya bila `is_available()` benar (probe `login status`, maks. 5 detik, stdin DEVNULL). Tanpa login, peran memakai mock deterministik. Alasan (ditemukan 20 Nov 2026): `codex` ada di PATH VM tetapi `codex login status` = "Not logged in"; menjalankan CLI yang belum login menggantung graph tanpa batas menunggu input interaktif. `run_cli` juga selalu memakai `stdin=DEVNULL` dan timeout maks. 120 detik per panggilan adapter. |
| A11 | **Anti-loop: riwayat dicatat node, edge hanya membaca** | `should_revise` (edge LangGraph) adalah pure-read. `hash_history` dan `finding_counts` ditulis oleh node `test` sebagai patch, karena mutasi di dalam edge function LangGraph TIDAK disimpan ke checkpoint — pencatatan di edge selalu hilang antar-langkah sehingga eskalasi hash tidak pernah terjadi (ditemukan 20 Nov 2026; sebelumnya loop audit→test→revise berjalan sampai cap `fix_iterations=5`). Hash dianggap berulang bila muncul ≥ 2x di riwayat. |
| A12 | **Semgrep tidak satu venv dengan FastMCP** | `semgrep` 1.186.0 membutuhkan `mcp==1.29.0`, sedangkan `fastmcp` 4.2.2 membutuhkan `mcp==2.3.0` — keduanya tidak bisa hidup di satu venv (ditemukan 20 Nov 2026). Keputusan: venv utama memakai `mcp==2.3.0` (FastMCP inti) dan gate semgrep memakai fallback regex deterministik bila binary tidak ada; semgrep binary dijalankan dari venv/CI terpisah bila dibutuhkan. Jangan instal semgrep ke `.venv` utama. |
| A13 | **A2A: format saja, tanpa klaim interop eksternal** | Modul `src/mufakat/a2a/` mengimplementasikan format protokol A2A (Agent Card JSON + Task/Message/Artifact + dispatcher lokal in-process). Interop dengan agent A2A eksternal (HTTP JSON-RPC) belum terverifikasi dan tidak diklaim. |
| A14 | **E2E dashboard via HTTP TestClient (Playwright belum terpasang)** | Playwright tidak terpasang di VM (tidak ada binary browser). E2E diuji lewat `tests/e2e/` memakai FastAPI TestClient (alur health → debat → detail run → daftar run). Bila Playwright terpasang nanti, E2E browser bisa ditambahkan; sampai saat itu statusnya "belum terpasang", bukan "lolos". |
| A15 | **Desktop Tauri, Temporal, E2B/Daytona: deferred** | Sengaja TIDAK dibangun di tahap ini. Desktop Tauri: belum ada kebutuhan multi-user/desktop; web + CLI cukup untuk MVP. Temporal (workflow tahan lama): checkpoint LangGraph + `resume` sudah cukup untuk MVP; Temporal menambah server + biaya. Sandbox cloud E2B/Daytona: butuh akun + API key berbayar; sandbox lokal (Docker/worktree + allowlist terminal) cukup untuk MVP. Ketiganya dicatat sebagai deferred, bukan "sudah ada". |

| A16 | **MUFAKAT Room: Manual Handoff adalah mode default** | Claude ROOM memakai extension (fillInput + readLastReply DOM) sebagai moderator, sedangkan V3 melarang extension/DOM scraping pada MVP dan mewajibkan Manual Handoff (Mode B). Keputusan 20 Nov 2026: default = manual handoff (engine Python `src/mufakat/room/`, state machine V3 Addendum F, respons dilabeli "user imported" + provenance). Assisted Fill via extension HANYA modul opt-in Fase 2 di `mufakat-room/` (scaffold, belum terverifikasi), tidak aktif default. Status per provider jujur: ChatGPT/Claude/Gemini/DeepSeek/Qwen = `manual_handoff`, Muse = `needs_policy_review`. |
| A17 | **Room: tidak ada auto-send, tidak ada pembacaan sesi provider** | Tidak ada kode (Python maupun TS) yang menekan Kirim/Enter, memanggil API internal situs AI, atau membaca cookie/token/localStorage/password. Pacing 20 dtk/situs + batas harian 40; secret scanner sebelum salin; tidak ada polling background. |
| A18 | **Room reuse, bukan duplikasi** | Konsensus Borda reuse `mufakat.consensus.voting`; gates/verdict reuse `mufakat.gates`; worktree/sandbox runner reuse `mufakat.sandbox` bila terpasang (fallback lokal + laporan jujur bila Docker tidak ada). Validasi path traversal dan native messaging host adalah kode baru khusus Room. Storage Room: JSONL + SQLite stdlib (padanan Dexie di browser). |
| A19 | **Satu engine AI Room di web (TypeScript); Python Room = layanan backend/referensi yang sinkron** | Penyelesaian temuan J audit ChatGPT (dua engine berjalan sendiri-sendiri), 20 Nov 2026. Satu-satunya engine AI Room di web adalah engine TypeScript di website Room (artifact `mufakat`). Engine Python (`src/mufakat/room/`) adalah layanan backend terpisah/referensi yang sinkron — dipakai CLI, MCP, dan demo mock — bukan engine kedua di dalam Room. Sumber kebenaran tunggal per lapisan: UI/state web → engine TS; logika handoff/pacing/secret scan/konsensus Python → `src/mufakat/room/`. Bila perilaku keduanya berbeda, yang berlaku adalah BLUEPRINT §17–§18; selisih wajib diperbaiki. |

## C. Cara mengubah dokumen ini

- Keputusan baru yang sudah disetujui owner: pindahkan dari bagian B ke
  bagian A dengan tanggal dan sumber keputusan.
- Jangan mengubah status **belum terverifikasi** menjadi diputuskan tanpa
  konfirmasi eksplisit dari owner.

## Keputusan integrasi (diambil saat pembangunan, 20 Nov 2026)

- **Layout kanonik: `src/mufakat/`** (sesuai Claude §7 dan `pyproject.toml` src-layout). Tree flat di root repo (`adapters/`, `consensus/`, `graph/`, `gates/`, `router/`, `sandbox/` di root) yang dibuat paralel oleh subagent sudah dipindah ke `src/mufakat/` dan dihapus dari root, karena tree flat membuat root menjadi paket `mufakat` bayangan dan memecah `isinstance` GateResult saat paket terimpor dua kali. `tests/test_smoke.py` yang menghapus `sys.modules` saat import juga sudah diperbaiki.
- **Checkpointer LangGraph:** `langgraph-checkpoint-sqlite` ditambahkan ke dependensi; bila paket itu tidak ada, graph jatuh ke `MemorySaver` (bukan gagal total).
- **Node graph async:** runner memakai `ainvoke` (invoke sinkron LangGraph menolak node async).
