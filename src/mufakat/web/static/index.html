Workspace

Git & PR

Status git tersedia lewat MCP tool git_status. Perubahan kode hanya masuk repo setelah gate lolos.

Testing

Pengujian dijalankan lewat MCP tool testing_run (pytest --collect-only) dan pytest di CI.

Security

Pemindai (semgrep, bandit, gitleaks, trivy) dicek lewat mufakat doctor dan MCP tool security_scan. Hasil scan disimpan di runs/<id>/gates/.

Memory
